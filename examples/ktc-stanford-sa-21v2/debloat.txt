# --- KEEP, even though some names look like bloat ---
# - com.mediatek.wwtv.tvcenter: Live TV. Do not disable unless you never watch it.
# - com.google.android.gms, com.android.vending: Play Services and Play Store.
# - com.homwee.* (firmware update, factory, picture, remote pairing) if present.
# - Streaming apps: Netflix, YouTube, Prime Video, Globoplay, Disney+, Max.
#
# --- Quirks on this firmware ---
# - Home claimants before the swap: me.efesser.flauncher/.MainActivity (the default),
#   then com.android.tv.settings/.system.FallbackHome. Only two, no setup wizard
#   claiming Home, because setupwraith was already disabled on this set.
#   Once setupwraith is enabled, Home can land on its RecoveryActivity and
#   crash-loop system_server (see the AIWA example in this repo).
# - "cmd package set-home-activity --user 0 <pkg>/<activity>" works on this set
#   and does not need the user to pick from a chooser dialog.
# - The screensaver is com.google.android.backdrop/.Backdrop. It is a DreamService
#   with NO settings activity ("cmd package query-activities" -> "No activities
#   found"), so it cannot be pointed at the user's Google Photos. Google Photos
#   is not installed on this set either. For photo slideshows you need a
#   third-party Dream app, chosen in Settings > Device Preferences > Screen saver.
# - The MultiMediaPlayer app is com.mediatek.wwtv.mediaplayer, apk in
#   /system_ext/priv-app/MultiMediaPlayerKtc/. Its main activity is
#   com.mediatek.wwtv.mediaplayer.mmp.MediaMainActivity.
# - The Wi-Fi Display app is com.mediatek.androidbox, apk in
#   /system_ext/app/WFDSinkTest/. The name is generic: on the AIWA-ai-pont-sa
#   set in examples/aiwa-ai-pont-sa/ this same package is a KEEP (remote pairing,
#   inputs). Always check the apk path before disabling it, not just the name.
# - Remote ADB port is not 5555 on this set. "adb connect <ip> <port>" worked on
#   43175; the port changed between sessions. Check Settings > Network, or run
#   "adb mdns services" if the TV offers wireless debugging pairing.
# - If "adb connect" says "No route to host" but the TCP port is open
#   (test with bash's /dev/tcp), the adb server holds a stale route:
#   "adb kill-server && adb start-server" then connect again.
#

# - Home resolves to com.gathin.tvhome/.MainActivity.
# - No entries for gathin in the crash buffer.
